LunarSync dispose maintenant d’un canal de mises à jour sur GitHub.

- Installation Windows x64 autonome : télécharge **LunarSync-Setup-1.2.0-win-x64.exe**.
- Les prochaines versions seront proposées dans **Mises à jour**, avec téléchargement, contrôle de signature et redémarrage en un bouton.
- Notification dans la zone de notification lorsqu’une nouvelle version est détectée.
- Dix configurations, sept macros prédéfinies, aperçu clavier, statistiques et panneau en jeu.
- Version portable : extrais entièrement **LunarSync-1.2.0-win-x64.zip**. La mise à jour en un clic nécessite l’installation.

Toutes les macros démarrent désactivées. La croix masque l’application ; **Quitter LunarSync** l’arrête. **Ctrl + Alt + F12** désactive les modes.

La clé privée de publication n’est pas distribuée. Le certificat d’éditeur Windows (Authenticode) n’est pas encore en place ; il est distinct de la signature vérifiée par le système de mise à jour.
