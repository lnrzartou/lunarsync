# LunarSync 1.2.1

Dans le panneau en jeu, l’état d’une macro configurée apparaît désormais en vert lorsqu’elle est activée (y compris pendant un maintien), et en rouge lorsqu’elle est désactivée. Les macros non configurées conservent leur couleur neutre.

L’aperçu de l’onglet Panneau en jeu utilise les mêmes couleurs.
